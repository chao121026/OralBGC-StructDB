Help

What is a MAG?

A metagenome-assembled genome reconstructed from oral microbiome sequencing data.

What is a BGC?

A biosynthetic gene cluster predicted here with antiSMASH. BGCs are computational predictions and should be interpreted as hypotheses.

What is a GCF?

A BiG-SCAPE gene cluster family. {{ brand.public_name }} labels the default GCFs as primary c0.3 assignments.

antiSMASH and BiG-SCAPE

antiSMASH predicts BGC regions and annotations. BiG-SCAPE groups related BGCs into GCFs at defined cutoffs.

BiG-SCAPE networks

The Networks page summarizes the primary c0.3 GCF layer, lists real class distributions, links to canonical BGS-GCF pages, provides curated BGS-mapped network edge-list downloads, and includes a Cytoscape.js viewer for bounded public subnetworks. The viewer uses BGS-BGC accessions as node IDs, preserves BiG-SCAPE distance values on edges, and leaves oversized networks download-only.

AlphaFold3, pLDDT, and compactness

Predicted structures are downloadable CIF files. AF3 QC availability means parsed confidence and compactness metrics are available. pLDDT summarizes local confidence; compactness describes broad shape/contact-density behavior.

Foldseek, probability, TM-score, and PDB categories

Foldseek compares predicted structures to PDB structures. Probability and TM-score indicate structural similarity, not functional proof. Weak/no-clear matches should be read as structurally under-characterized, not as therapeutic candidates.

Three availability layers

Structure available means an approved CIF exists. AF3 QC available means parsed QC metrics exist. Foldseek/PDB annotation available means a Foldseek best-hit row exists.

How to browse and filter

Use MAGs, BGCs, primary c0.3 GCFs, Proteins, and Structures pages. Filters are server-side and preserve query-string state where practical.

Stable BGS accessions

Each MAG, BGC, primary c0.3 GCF, protein, and predicted structure has a stable BGS accession such as BGS-MAG-000001, BGS-BGC-000001, BGS-GCF-C03-0001, BGS-PRT-000001, or BGS-STR-000001. Original PHRC identifiers are preserved as searchable provenance metadata, and legacy URLs redirect to the canonical accession URL.

Downloads and citation

The Downloads page contains public allowlisted files with checksums. {{ brand.public_name }} broadens structural coverage of BGC-encoded proteins from the oral microbiome by integrating AlphaFold 3 models with biosynthetic context, quality-control metrics, and structural-similarity annotations.

Future HROM integration

Future HROM rows will use the same schema with a dataset label, preserving public identifiers and routes.

Worked examples

Start with protein browse, open a structure-bearing protein, then follow its BGC, MAG, and primary c0.3 GCF links.
