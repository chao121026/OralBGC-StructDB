PHRC_BGCStructDB

A structure-enabled biosynthetic gene cluster protein resource for oral microbiome MAGs

This public database links MAG-derived BGCs and primary c0.3 BiG-SCAPE GCFs to encoded proteins, predicted structures, AF3 QC metrics where available, and Foldseek/PDB structural annotations where available.

Why This Resource Is Different

PHRC_BGCStructDB emphasizes protein-level structure context for oral microbiome MAG-associated BGCs. Structure availability, AF3 QC, and Foldseek/PDB annotation are tracked as distinct public data layers.

  • MAG-resolved oral microbiome context
  • Protein-level BGC annotation
  • Downloadable CIF structures
  • AF3 confidence and compactness metrics when available
  • Systematic Foldseek/PDB comparison when available

Data Layer Boundaries

Structure availability means an approved CIF file can be served. AF3 QC and Foldseek/PDB annotation are separate release layers and are counted independently throughout the site.
