# Cross-Link Audit

Verified navigation patterns implemented in this phase:

- MAG detail links to filtered BGC browse and protein browse.
- BGC detail links to MAG, primary c0.3 GCF when assigned, and protein records.
- GCF detail links to member BGC, MAG, and protein records.
- Protein detail links remain available to BGC/MAG/GCF identifiers and CIF download where structure exists.
- Structure browse links to protein detail/viewer pages.
- Search results use canonical record URLs.
- Downloads and Networks use strict file-key download links, not raw paths.

Known follow-up: chart-click-to-filter interactions are not yet implemented; charts remain explanatory summaries.
